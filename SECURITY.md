# Security Policy

## Reporting a Vulnerability

We take the security of pgmoat seriously. If you believe you have found a security vulnerability in pgmoat, please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report security issues by emailing:
**security@kitalonlabs.com**

### Policy and Timeline

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 72 hours.
- **Assessment:** We will confirm the vulnerability and determine how it affects pgmoat.
- **Fix and Disclosure:** We follow a 90-day coordinated vulnerability disclosure policy. We will keep you informed of our progress throughout remediation.
- **Advisories:** Public disclosures and CVEs are published via GitHub Security Advisories.
