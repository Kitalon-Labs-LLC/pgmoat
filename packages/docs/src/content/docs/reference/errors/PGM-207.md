# PGM-207: Relation not allowed: hidden, unknown, outside exposed schemas, or a system catalog

## When you see it
Relation not allowed: hidden, unknown, outside exposed schemas, or a system catalog

## What pgmoat did
pgmoat intercepted the operation safely before executing any unsafe commands on Postgres. The attempt was logged in the audit trail.

## Kind
`refused`

## Fix
Check configuration and permissions

## Verification
Run `pgmoat validate` or `pgmoat doctor` to confirm your role and configuration satisfy safety guarantees.
