# Schema Annotations

Customize what AI agents see and query in \`pgmoat.yaml\`:

\`\`\`yaml
tables:
  users:
    description: "Registered user profiles"
    columns:
      id: { description: "Primary identifier" }
      email: { description: "User email", sensitive: medium }
      password_hash: { hidden: true }
      api_key: { hidden: true }

  admin_logs:
    hidden: true
\`\`\`

## Flags

- \`hidden: true\`: Completely hides table or column from introspection, and rejects queries attempting to access it with \`PGM-207\` or \`PGM-208\`.
- \`sensitive: high | medium | low\`: Redacts literal values in audit logs and masks values in \`sample_table\`.
- \`untrusted: true\`: Flags user-generated content so LLMs treat data as untrusted text.
